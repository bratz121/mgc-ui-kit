# 03. Компоненты

Базовые компоненты — shadcn/ui (стиль `base-nova`, примитивы **Base UI**), лежат в
`src/components/ui`. Продуктовые — в `src/components/mgc`, `src/components/platform`,
`src/components/brand`. Живые примеры и код — на витрине (`npm run dev`).

Общие правила для всех компонентов:

- Стилизуем через варианты (`variant`, `size`), а `className` — только для раскладки.
- Иконки внутри кнопок и бейджей — с `data-icon="inline-start|inline-end"`, без классов размера.
- Кастомный триггер — через `render` (Base UI), не `asChild`: `<DialogTrigger render={<Button />}>`.
- Ссылка-кнопка: `<Button render={<a href="…" />} nativeButton={false}>`.
- Отступы — `flex gap-*`, не `space-y-*`. Квадратные размеры — `size-*`.

## Button
**Назначение:** запустить действие.

| Свойство | Значения | Когда |
|---|---|---|
| `variant` | `default` | Основное действие (одно на экран/форму) |
| | `outline` | Вторичное действие, «Отмена» |
| | `secondary` | Альтернативное, «Черновик» |
| | `ghost` | Действия в тулбарах, таблицах, шапке |
| | `destructive` | Разрушающее действие (мягкий красный) |
| | `link` | Действие-ссылка в тексте |
| `size` | `xs` 24 · `sm` 28 · `default` 32 · `lg` 36 · `icon*` | `lg` — шапка и сенсорные терминалы |

**Состояния:** hover, focus-visible (кольцо), active (сдвиг на 1px), disabled (50%), загрузка (`Spinner` + `disabled` + текст «Сохранение…»).

**Правила:** подпись — глагол; основная справа в футере; кнопка-иконка — `sr-only` + `Tooltip`;
красной основной кнопки нет.

## Badge
**Назначение:** короткая метка — категория, тег, изменение показателя.

`variant`: `default` · `secondary` · `outline` · `ghost` · `link` · **`success` · `warning` · `info` · `destructive` · `brand`** (добавлены в ките).
Для статусов сущностей используйте `StatusBadge`.

## StatusBadge — `components/mgc/status-badge.tsx`
**Назначение:** единый словарь статусов для всех модулей.

| `status` | Подпись | Цвет |
|---|---|---|
| `new` | Новая | info |
| `in_progress` | В работе | warning |
| `waiting` | Ожидание | secondary |
| `done` | Выполнена | success |
| `stopped` | Остановка | destructive |
| `cancelled` | Отменена | secondary |

`label` переопределяет подпись («Остановка 14 мин»). Новый статус — сначала в словарь и в эту таблицу.

## Alert
**Назначение:** сообщение в потоке страницы, не исчезает само.
`variant`: `default` · `destructive` · **`info` · `success` · `warning` · `critical`** (мягкая подложка, добавлены в ките).
Состав: иконка + `AlertTitle` + `AlertDescription`. Критичный alert на дашборде — сразу под заголовком.

## Card
Полная композиция: `CardHeader` → `CardTitle` / `CardDescription` / `CardAction` → `CardContent` → `CardFooter`.
`size="sm"` — компактная. Таблица внутри карточки: `className="gap-0 py-0"` на `Card`, таблица без обёртки.

## StatCard — `components/mgc/stat-card.tsx`
**Назначение:** KPI-показатель.

| Свойство | Тип | Описание |
|---|---|---|
| `label` | string | Название показателя |
| `value` | ReactNode | Значение, уже отформатированное (`"1 248"`) |
| `unit` | string? | Единица: шт, %, мин |
| `delta` | number? | Изменение в %, знак определяет стрелку |
| `higherIsBetter` | boolean = true | `false` для простоев, брака — рост будет красным |
| `tone` | `none · steel · ochre · sage · rose · brand` | Цветная полоса сверху для категорий/статусов |
| `icon` | ReactNode? | Иконка в правом верхнем углу |

## Формы: Field, Input, InputGroup, Textarea, Select
- Раскладка — только `FieldGroup` + `Field` (+ `FieldSet`/`FieldLegend` для групп).
- Ошибка: `data-invalid` на `Field`, `aria-invalid` на контроле, текст в `FieldError`.
- Недоступно: `data-disabled` на `Field`, `disabled` на контроле.
- Единицы измерения и иконки — `InputGroup` + `InputGroupAddon` (не абсолютное позиционирование).
- **Select (Base UI)** требует проп `items`; плейсхолдер — элемент `{ label, value: null }`.

## Выбор: Checkbox, RadioGroup, Switch, ToggleGroup, Tabs
| Компонент | Когда |
|---|---|
| Checkbox | Независимые флаги, выбор строк таблицы |
| RadioGroup | Один из 2–5 видимых вариантов |
| ToggleGroup | Режим/период: Смена · День · Неделя (Base UI: `defaultValue` — массив) |
| Switch | Настройка, применяется сразу, без кнопки «Сохранить» |
| Select | Один из многих (> 5) |
| Tabs | Разные виды одних данных. Не навигация между разделами |

## DataTable — `components/mgc/data-table.tsx`
**Назначение:** основной список сущностей (TanStack Table v8).

Возможности: глобальный поиск; фильтры по значениям с поиском и счётчиками (`facets`); сортировка по клику на шапку
(`aria-sort`); меню «Вид» — видимость колонок и плотность (компактно / обычно / просторно); выбор строк и панель
массовых действий (`bulkActions`); клик по строке (`onRowClick` → карточка в `Sheet`); пагинация с выбором размера;
закреплённая шапка (`maxHeight`); скелетон (`loading`); пустое состояние со сбросом фильтров.

**Адаптивность — по ширине контейнера (container queries), а не окна:**
- `meta.hideBelow` — второстепенные колонки скрываются, когда таблице тесно;
- уже 576px строки становятся карточками, `meta.mobile` задаёт роль поля.

| Мета колонки | Значения | Назначение |
|---|---|---|
| `label` | string | Подпись в меню «Вид» и в карточке |
| `align` | `left · right` | `right` — числа, `tabular-nums` |
| `hideBelow` | `md · lg · xl` | Скрыть при узком контейнере (< 768 / 896 / 1024px) |
| `mobile` | `title · subtitle · badge · hidden` | Роль в карточке |

Хелперы: `selectColumn()`, `<DataTableColumnHeader column title />`.

## Table
Простая таблица для коротких фиксированных списков (≤ 10 строк, без фильтров). Плотность — `data-density` на `<Table>`.
- Первая колонка — идентификатор (`font-mono text-xs`).
- Числа — `text-right tabular-nums`, единица в шапке («Простой, мин»).
- Действия строки — `DropdownMenu` с триггером `⋯` (`ghost`, `icon-sm`); разрушающее — `variant="destructive"` в отдельной группе.
- Пустая выборка — `Empty` с действием. > 20 строк — `Pagination`.

## Оверлеи: Dialog, AlertDialog, Sheet, Popover, DropdownMenu, Tooltip
| Компонент | Когда |
|---|---|
| Dialog | Короткая задача (1–4 поля) без ухода со страницы |
| AlertDialog | Подтверждение разрушающего/необратимого действия |
| Sheet | Фильтры, просмотр записи сбоку от таблицы |
| Popover | Справка, мини-форма у элемента |
| DropdownMenu | Список действий |
| Tooltip | Подпись к кнопке-иконке, расшифровка сокращения |

У `Dialog`, `Sheet`, `AlertDialog` всегда есть `Title` (для скринридеров; можно `sr-only`).
`z-index` вручную не задаётся. Диалог из диалога не открывается.

## Обратная связь: Toast (sonner), Progress, Skeleton, Spinner, Empty
| Компонент | Когда |
|---|---|
| `toast.success/error()` | Результат действия. Ошибка — с причиной и выходом |
| Progress | Известная длительность / доля (выгрузка, наработка до ТО) |
| Skeleton | Первая загрузка блока с известной структурой |
| Spinner | Короткое ожидание в кнопке или строке |
| Empty | Нет данных — с объяснением и действием |

## ChartCard — `components/mgc/chart-card.tsx`
Карточка графика с переключателем **«График / Таблица»** (`data` + `columns`). Табличный вид обязателен: данные
не должны быть доступны только через цвет и форму.

## Chart
Марки (dataviz): столбец ≤ 24px, скругление 4px только у конца данных (`BAR_RADIUS`), стек — зазор 2px цветом фона;
линия 2px, маркер r = 4 с кольцом 2px; площадь — заливка 10%; сетка сплошная 1px, только горизонтальная;
**одна ось Y**; цель и норматив — `ReferenceLine` с подписью. Виды на витрине: столбцы, стек, Парето, линии,
площадь, кольцо (≤ 4 долей), комбинированный (одни единицы), точечная, bullet «факт vs цель», тепловая карта.

Обёртка над Recharts. Цвета — только `var(--chart-N)` через `ChartConfig`.
Всегда `ChartTooltip`; при 2+ сериях — `ChartLegend`. Ось Y — без линии, сетка — только горизонтальная.

## TagInput — `components/mgc/tag-input.tsx`
Множественный ввод: значение → **Enter** (или `,` `;` Tab) → чип → следующее. Вставка списка из Excel разбивается
по строкам и запятым. Backspace в пустом поле удаляет последний чип. Дубли не добавляются.

| Свойство | Назначение |
|---|---|
| `value / onChange` | `string[]` |
| `transform` | Нормализация (например, `toUpperCase` для кодов) |
| `validate` | Вернуть текст ошибки → `onError` → `FieldError` |
| `max` | Лимит количества |
| `mono` | Моноширинные чипы для кодов |

## DatePicker / DateRangePicker — `components/mgc/date-picker.tsx`
Только календарь кита — **системный `input type="date"` не используем** (разный вид в браузерах, чужая локаль).
- `DatePicker`: поле с маской ДД.ММ.ГГГГ (можно печатать `30112026`), кнопка календаря, выбор месяца и года,
  «Сегодня» и «Очистить», `disabled` — недоступные даты (`{ before: new Date() }`).
- `DateRangePicker`: быстрые периоды (сегодня, вчера, эта/прошлая неделя, этот/прошлый месяц, 30 дней),
  два месяца на десктопе и один на телефоне, применение кнопкой.
- Хелперы: `formatDate`, `parseDate`, `formatRange`, `rangePresets`.

## WidgetBoard / KanbanBoard / SortableList — `components/mgc/dnd.tsx`
Перетаскивание на dnd-kit: мышь, касание (долгое нажатие 200 мс — не мешает прокрутке), клавиатура
(Пробел — взять, стрелки, Пробел — положить, Esc — отмена). Объявления для экранного диктора — на русском.
- `WidgetBoard` — сетка 3/2/1 колонки, `size: 1 | 2 | 3`, режим `editing`, `DragOverlay`.
- `KanbanBoard` — перенос карточек между колонками (`item.column`) и внутри колонки.
- `SortableList` — вертикальный список.
- `DragHandle` — перетаскивание только за ручку (32px, 44px на тач-экране).

## Toast (sonner)
Статусные тосты окрашены токенами: `toast.success / error / warning / info` → мягкая подложка, цветной текст и рамка.

## Logo — `components/brand/logo.tsx`
`variant`: `horizontal` (по умолчанию) · `vertical` · `mark` · `mgc-horizontal` · `mgc-vertical`.
Цвет — от текста (`text-foreground`, `text-white`, `text-brand`). Мин. высота: горизонтальный 20px, знак 16px.

## PlatformSidebar / PlatformHeader — `components/platform/`

## Правки upstream-компонентов (`// MGC:`)
- `dropdown-menu` — ширина меню по содержимому, а не по кнопке-якорю (иначе меню «⋯» сжимается).
- `table` — шапка на подложке, плотность через `data-density`, выбранная строка — `brand-soft`.
- `badge`, `alert` — статусные варианты; `sonner` — статусные цвета.
- `sidebar` — постоянное меню с 1024px (уже — выезжающая панель), подписи на русском.
- `carousel`, `use-mobile` — исправления под правила React 19 (`useSyncExternalStore`).

## Навигация между приложениями — `components/platform/cross-nav.tsx`

| Компонент | Назначение |
|---|---|
| `ModuleSwitcher` | Лаунчер всех модулей площадки в шапке; текущий подсвечен акцентом |
| `ModuleLink` | Ссылка в смежный модуль: плитка + название модуля + что откроется; новая вкладка; несёт контекст в URL |
| `RelatedRecords` | Связанные записи из других модулей с плитками и статусами |

## AsyncButton / HoldButton — `components/mgc/action-buttons.tsx`
- `AsyncButton onAction={() => promise}` — покой → загрузка (спиннер, блокировка, `aria-busy`) → «Готово» 1.5 с → покой. Двойная отправка невозможна. Ошибку показывает вызывающий код (`toast.error`).
- `HoldButton onConfirm holdMs={1500}` — подтверждение удержанием для критичных действий на терминале. Заливка показывает прогресс, отпустили раньше — отмена. Клавиатура: удерживать Пробел/Enter.

## OkNok — `components/mgc/ok-nok.tsx`
Результат точки контроля: ОК (годен) / НОК (не годен) / Н/П (`allowNa`). Цвет + иконка + слово. `size="lg"` — терминал (56px).
Стрелки ← → переключают. Паттерн чек-листа: при НОК — обязательное описание и фото, итог «годен / на доработку», принять нельзя, пока не проверены все точки.

## ShowMoreList / ExpandableText — `components/mgc/disclosure.tsx`
«Под кат»: `ShowMoreList initial step` — «Показать ещё K из N» и «Свернуть»; `ExpandableText lines` — «Читать полностью»
появляется, только если текст не влез. Дополнительно: `Collapsible` для редких полей формы, раскрытие строки таблицы.

## InteractiveLegend — `components/mgc/chart-legend.tsx`
Легенда с поведением: клик — скрыть/показать серию (одна всегда остаётся), наведение/фокус — подсветить (остальные 20%),
двойной клик — «только эта», «Показать все». `mark: rect | line | dot` повторяет форму метки; `layout: inline | list`.
Хук `useSeriesVisibility(keys)` → `hidden, toggle, only, reset, setHover, opacity(key)`.

## Аналитика: поведение графиков
- **Проваливание**: клик по столбцу/сектору → уровень ниже; крошки уровней и «Назад»; курсор-рука и подсказка. Не глубже 3–4 уровней.
- **Масштаб**: пресеты периода, выделение участка мышью (`ReferenceArea`), рамка-навигатор (`Brush`), «Сбросить масштаб».
- **Масштабируемость**: по ширине контейнера — на узкой ширине горизонтальные столбцы и сокращённые подписи.
- **Фильтры**: одна строка над всеми графиками, период первым; при обновлении графики остаются на месте с прозрачностью 50%.
