# 02. Токены

Источник правды — [`src/styles/tokens.css`](../src/styles/tokens.css). Формат цвета — OKLCH
(так устроены токены shadcn/ui v4). HEX указан для справки и сверки с брендбуком.

Три слоя:

1. **Бренд-палитра** `--mgc-*` — цвета из брендбука. Только для построения семантики.
2. **Семантика** `--background`, `--primary`, `--success`… — то, что используют компоненты.
3. **Утилиты Tailwind** `bg-primary`, `text-success`… — генерируются в `src/index.css` (`@theme inline`).

### Статусы

Каждый статус — пара: насыщенный цвет (текст, иконка) + мягкая подложка.

| Статус | Токены | Смысл |
|---|---|---|
| Успех | `--success`, `--success-soft` | Выполнено, норма, в плане |
| Внимание | `--warning`, `--warning-soft` | В работе, отклонение, скоро срок |
| Инфо | `--info`, `--info-soft` | Новое, справка |
| Критично | `--destructive`, `--destructive-soft` | Остановка, авария, ошибка |

### Графики

Палитра серий проверена валидатором dataviz (`validate_palette.js`): светлота в рабочей полосе,
насыщенность ≥ 0.10, различимость соседних цветов при дальтонизме (ΔE ≥ 8) и обычном зрении (ΔE ≥ 15),
контраст с фоном ≥ 3:1 — **в обеих темах, без предупреждений**. Тона — из дополнительной палитры брендбука,
насыщенность поднята до порога различимости. Зелёного в сериях нет: он занят статусом «Успех».

| Токен | Светлая | Тёмная | Тон |
|---|---|---|---|
| `--chart-1` | `#365BA1` | `#5279C1` | сталь (факт, основная серия) |
| `--chart-2` | `#B05459` | `#B65A5F` | роза |
| `--chart-3` | `#9D8D26` | `#978400` | олива |
| `--chart-4` | `#009EB9` | `#0096B7` | сланец (план, норматив) |
| `--chart-5` | `#B26E27` | `#B36300` | охра |

Порядок фиксирован, цвет закреплён за сущностью. `StatCard tone` использует те же цвета
(`steel · rose · olive · slate · ochre`), чтобы карточка совпадала со своей серией на графике.

### Последовательная шкала

`--seq-1…5` — один тон (сталь), от светлого к тёмному. Для тепловых карт и интенсивности.
В тёмной теме шкала инвертирована по светлоте (больше = светлее).

## Типографика

| Токен | Значение |
|---|---|
| `--font-sans` | IBM Plex Sans Variable (100–700, кириллица) |
| `--font-mono` | IBM Plex Mono 400/500 |

Шкала (Tailwind): `text-xs` 12 · `text-sm` 14 (основной) · `text-base` 16 · `text-lg` 18 ·
`text-2xl` 24 (заголовок страницы) · `text-3xl` 30 (KPI) · `text-4xl` 36.
Начертания: 400, 500, 600. Цифры в таблицах и KPI — `tabular-nums`.

Почему Plex: есть в брендбуке среди фирменных кандидатов, одна семья закрывает и текст,
и моноширинные коды/номера, хорошая кириллица, спокойный характер для плотных экранов.
Шрифт меняется одной строкой — `--font-sans-family` в `tokens.css`.

## Отступы и размеры

Шкала Tailwind (шаг 4px). Стандарты:

| Что | Значение |
|---|---|
| Шапка рабочей области | 64px (`h-16`) |
| Боковое меню | 360px (`--sidebar-width: 22.5rem`) |
| Поле/кнопка по умолчанию | 32px (`h-8`), `lg` — 36px |
| Внутренний отступ карточки | 16px (`--card-spacing`), `sm` — 12px |
| Отступ между карточками | 16px (`gap-4`) |
| Поля страницы | 16px мобильный · 32px десктоп (`px-4 md:px-8`) |

## Сенсорные экраны

На устройствах с `pointer: coarse` (терминалы, планшеты, телефоны) самостоятельные контролы — кнопки,
поля, селекты, пункты меню — получают минимум **44px**; вкладки и сегменты — 40px. Вложенные кнопки
(внутри поля, чипа, группы кнопок) не увеличиваются, чтобы не ломать контейнер. Поля ввода — 16px,
чтобы iOS не масштабировал страницу при фокусе. Определяем по типу указателя, а не по ширине экрана.

## Поверхности браузера

Выделение текста — бренд 22%, каретка — `--brand`, тонкие скроллбары из `--foreground` 22%,
цифры в таблицах — `tabular-nums` по умолчанию.

## Акценты модулей

Файл [`src/styles/modules.css`](../src/styles/modules.css). У каждого модуля — цвет «слеша» из его логотипа
(`promo/logos_pk.zip`), он же из дополнительной палитры брендбука. Шкала построена в OKLCH с постоянным тоном,
контраст подобран светлотой (better-colors). Модуль задаётся атрибутом `data-module` на `<html>` (`ModuleProvider`)
или на любом контейнере.

| Токен | Роль | Требование |
|---|---|---|
| `--module-mark` | Точный цвет логотипа: декоративные метки, тёмные поверхности | Не для текста — на светлом фоне часто < 3:1 |
| `--module-strong` | Текст, иконки, ссылки модуля, полоса активного пункта, линия вкладки, прогресс | ≥ 4.5:1 на фоне и на `soft`, обе темы |
| `--module-soft` | Выбранная строка, панель выделения, аватар, бейдж модуля | — |
| `--module-solid` / `-foreground` | Заливка с текстом поверх | ≥ 4.5:1 |
