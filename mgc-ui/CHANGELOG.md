# Changelog

## 0.3.0 — 27.11.2026

**Акценты модулей**
- 14 модулей платформы со своим цветом из логотипа (`promo/logos_pk.zip`): `modules.css`, `data-module`, `ModuleProvider`.
- Шкала mark / strong / soft / solid в OKLCH, контраст strong ≥ 4.5:1 в обеих темах (better-colors).
- Акцент применяется к полосе активного пункта меню, вкладкам, прогрессу, выбранным строкам, аватару, нижнему меню.
- Логотипы модулей в проекте; `ModuleTile` для модулей без плитки pc_ui_kit.

**Навигация**
- `ModuleSwitcher` (лаунчер в шапке), `ModuleLink`, `RelatedRecords`, `BackLink`, `RecordPager`; страница «Навигация» по трём уровням.

**Кнопки**
- `AsyncButton` (загрузка → готово, защита от двойной отправки), `HoldButton` (подтверждение удержанием).
- Матрица вид × размер, составные кнопки, поведение и состояния, кнопки в формах.

**Выбор и контроль**
- `OkNok` и чек-лист ОТК; «под кат»: `ShowMoreList`, `ExpandableText`, дополнительные поля, раскрытие строк;
  чекбоксы с «выбрать все» (промежуточное состояние), радио-карточки.

**Аналитика**
- Проваливание (столбцы и кольцо), масштаб (выделение, рамка, пресеты), `InteractiveLegend`, масштабируемость по контейнеру, фильтры дашборда.

**Исправления**
- Мобильные экраны «плыли»: блоки с горизонтальной прокруткой сжимались в колонке фиксированной высоты — запрещено сжатие.

## 0.2.0 — 27.11.2026

**Новые компоненты**
- `DataTable` (TanStack Table v8): поиск, фильтры со счётчиками, сортировка, колонки и плотность, массовые действия,
  карточка записи в Sheet, пагинация, закреплённая шапка, скелетон; на узком контейнере — карточки.
- `TagInput` — множественный ввод (Enter → чип), вставка списков, проверка формата, лимит.
- `DatePicker`, `DateRangePicker` — календарь кита с маской ввода и быстрыми периодами (вместо системного `type="date"`).
- `ChartCard` — график + табличный вид; 10 видов диаграмм по правилам dataviz.
- `WidgetBoard`, `KanbanBoard`, `SortableList`, `DragHandle` — перетаскивание (dnd-kit), включая клавиатуру.
- Мобильные: `MobileHeader`, `BottomNav`, `ActionBar`, `Fab`, `ChipScroller`, `MobileSection`, `Numpad`.
- 17 компонентов shadcn: accordion, aspect-ratio, button-group, carousel, collapsible, combobox, command,
  context-menu, drawer, hover-card, input-otp, item, menubar, native-select, navigation-menu, resizable, slider.

**Токены**
- Палитра графиков пересчитана и проверена валидатором dataviz (обе темы, без предупреждений); добавлена шкала `--seq-1…5`.
- Сенсорные экраны: контролы ≥ 44px по `pointer: coarse`; выделение, каретка, скроллбары — из палитры.

**Исправления**
- Меню «⋯» сжималось до ширины кнопки и резало текст — ширина по содержимому.
- Тосты без цвета — статусные цвета токенов.
- Мобильная вёрстка «плыла»: увеличенные цели касания ломали контейнеры фиксированной высоты — теперь только самостоятельные контролы.
- Меню 360px сжимало контент на планшете — постоянное меню с 1024px.
- В окне «Перенести ТО» был системный календарь браузера — заменён на DatePicker кита.

**Витрина**
- Поиск `Ctrl+K` по страницам и компонентам, хлебные крошки, оглавление страницы, «Назад / Далее»,
  сворачиваемые группы в меню, переключатель ширины превью; новые страницы: иконки, выпадающие списки,
  специальный ввод, модальные окна, навигация, раскладка, виджеты, мобильные компоненты и экраны.

## 0.1.0 — 27.11.2026

Первая версия.

**Основа**
- Vite + React 19 + TypeScript + Tailwind CSS v4 + shadcn/ui (`base-nova`, Base UI), иконки lucide.
- Токены по брендбуку MGC GROUP: бренд-палитра, дополнительная палитра, семантика,
  статусы (success / warning / info / destructive + мягкие подложки), 5 цветов графиков,
  светлая и тёмная темы. Файл `src/styles/tokens.css` не зависит от фреймворка.
- Шрифты IBM Plex Sans (variable) + IBM Plex Mono.
- Логотип MGC GROUP в 5 вариантах (векторы из брендбука, `currentColor`).

**Компоненты**
- 37 компонентов shadcn/ui; служебные подписи переведены на русский.
- Badge: варианты `success`, `warning`, `info`, `brand`.
- Alert: варианты `info`, `success`, `warning`, `critical`.
- Новые: `StatCard`, `StatusBadge`, `PlatformSidebar`, `PlatformHeader`, `Logo`.
- `use-mobile` переписан на `useSyncExternalStore`.

**Каркас**
- Боковое меню повторяет текущий `SideBar.vue`: 360px, знак «ПК», площадка, плитки модулей
  из pc_ui_kit, раскрывающиеся разделы текущего модуля, пользователь + таймер сессии + выход.

**Документация**
- Витрина с примерами, кодом и правилами; спецификации в `docs/`.
