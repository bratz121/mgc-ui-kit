# ui-kit

| Папка / файл | Что это |
|---|---|
| [`mgc-ui/`](mgc-ui/README.md) | UI-кит: код, витрина-документация, спецификации (`mgc-ui/docs/`) |
| `brand/` | Логотипы MGC GROUP в SVG (извлечены из брендбука, `currentColor`) |
| `references/` | Визуальные референсы |
| `MGC_GROUP_identity_result_compressed (1).pdf` | Брендбук MGC GROUP |

Брендбук и визуальные референсы хранятся локально и не входят в Git. Для сборки витрины они не нужны.

Запуск витрины:

```bash
cd mgc-ui
npm install
npm run dev
```
